セムカンカメラ

01基本の流れ

  1. 取り込む：ホームで登録単位を選び、「カメラで撮影」または「写真から選ぶ」をタップします。
  2. 確認する：画像の四隅や領収書の枠を合わせ、読み取り後に日付・支払先・摘要・金額を確認します。
  3. 保存する：確認した支出を端末に保存します。
  4. 送信する：ホームの「セムカン本体へ送信」から対象を選び、送信します。

撮影・確認・保存はログインせずに利用できます。セムカン本体への送信には、ログインとインターネット接続が必要です。

02登録単位を選ぶ

ホームの「登録単位」をタップし、領収書から作成する支出の件数を選びます。選択後は「この登録単位を使う」をタップしてください。

1枚 → 1件

領収書1枚から、支出を1件作成します。

例：1枚の領収書をそのまま登録する。

複数枚 → 1件

複数の領収書の金額を合計し、支出を1件作成します。

例：同じ支出にまとめたい領収書を一緒に登録する。

複数枚 → 複数件

領収書ごとに、支出を1件ずつ作成します。

例：3枚の領収書から3件の支出を登録する。

複数枚を取り込む場合は、最大8枚の領収書をA4台紙に並べて撮影してください。領収書同士が重ならないように、間隔を空けます。

03領収書を1枚取り込む

  1. 登録単位を「1枚 → 1件」にします。
  2. 「カメラで撮影」をタップして領収書全体を撮影します。保存済みの画像を使う場合は「写真から選ぶ」をタップします。
  3. 「領収書の確認」で、画像の四隅が領収書の角に合っているか確認し、ずれている場合は動かして調整します。
  4. 四隅を確定すると、画像の傾きを補正して文字を読み取ります。処理が終わるまでお待ちください。
  5. 読み取り結果を確認・修正し、「保存」をタップします。すぐに送信する場合は「送信」をタップします。

撮影時は「標準」または「離れて撮影」を選べます。領収書全体が収まり、文字にピントが合う位置で撮影してください。

きれいに撮影するコツを見る

04複数の領収書を取り込む

  1. 登録単位を「複数枚 → 1件」または「複数枚 → 複数件」にします。
  2. A4台紙に領収書を最大8枚並べ、「カメラで撮影」で台紙全体を撮影します。保存済みの台紙画像は「写真から選ぶ」で取り込めます。
  3. 「台紙の確認」で四隅を台紙の角に合わせ、確定します。
  4. 領収書の枠を確認します。画像上の枠や番号ボタンで対象を選び、位置や四隅を調整します。枠がない領収書は「＋」で追加し、不要な枠はごみ箱ボタンで削除します。
  5. すべての領収書に枠があることを確認し、「確定」をタップして文字を読み取ります。

枠のない領収書は登録されません。枠の数と領収書の枚数を照らし合わせ、1枚につき1つの枠が合っていることを確認してください。

「複数枚 → 1件」を選んだ場合

共通の日付・支払先・摘要を入力し、番号ごとの金額と合計金額を確認します。「保存」で1件の支出として保存します。画像には領収書の番号が付きます。

「複数枚 → 複数件」を選んだ場合

番号を切り替えながら、各領収書の日付・支払先・摘要・金額を確認します。不要な領収書は登録対象から削除できます。全件の確認が終わったら「一括保存」をタップします。

05読み取り結果を確認・修正する

自動で読み取った内容は、必ず原本画像と照らし合わせてください。文字を読み取れなかった場合も、同じ画像を見ながら手入力できます。

日付
領収書に記載された日付を確認します。
支払先
店舗名や会社名など、支払いの相手先を入力します。
摘要
支出の内容を入力します。
金額
登録する金額を確認します。必要に応じて計算式を入力できます。

画像の文字を選んで入力する

  1. 修正する項目を選び、画像から文字を選択する操作に切り替えます。
  2. 画像上の文字の枠をタップして、選んだ項目へ入力します。
  3. 支払先・摘要は複数の文字枠を選べます。最初の選択で現在の入力を置き換え、2つ目以降は選んだ順に追加します。

画像は2本の指で拡大・縮小でき、拡大後は動かして細部を確認できます。入力欄は手入力でも修正できます。

金額を計算して入力する

金額欄では、足し算・引き算・掛け算・割り算・％を含む式を使えます。たとえば「1000 + 500」と入力すると、計算結果は1,500円になります。式だけでなく、表示された計算結果も確認してください。

06保存した支出を確認・編集する

  1. ホームの「未送信の支出」から、確認したい支出をタップします。
  2. 保存した原本画像と入力内容を確認し、必要な項目を修正します。
  3. 「保存」をタップして変更を保存します。

不要な支出は、詳細画面の「削除」から削除できます。確認画面で内容を確認してから確定してください。

保存した支出と画像は端末内に保管されます。「保存」だけではセムカン本体へ送信されません。支出を削除すると、原本画像も削除されます。

07セムカン本体へ送信する

  1. インターネットに接続し、ホームの「セムカン本体へ送信」をタップします。
  2. 未ログインの場合は、アカウントとパスワードでログインします。ワンタイムパスワードが求められた場合は入力します。
  3. 送信する支出を選びます。すべて選ぶ場合は「全選択」を使います。
  4. 対象を確認して送信し、完了するまでお待ちください。
  5. メニューの「セムカン本体へ」からセムカンを開き、送信した内容を確認します。

送信に成功した支出は、画像とともに端末から自動削除されます。送信後の内容はセムカン本体で確認してください。

途中で送信に失敗すると、その時点で送信を停止します。成功した分は送信済みで、失敗した分とそれ以降の支出は端末に残ります。接続やログイン状態を確認し、残った支出を再送してください。

読み取り後の確認画面や保存済み支出の詳細画面にある「送信」からも、その支出を送信できます。

08設定を変更する

ホーム左上のメニューボタンから「設定」を開きます。

開始時の撮影方法

1枚だけの撮影を始めるときの方法を、「前回の選択を使用（おすすめ）」「標準（1×）」「離れて撮影（1.75×）」から選べます。

四隅調整時に拡大鏡を表示

オンにすると、四隅を動かしている位置を拡大して確認できます。細かな枠調整にご利用ください。

09困ったときは

文字が正しく読み取れません

画像を確認し、日付・支払先・摘要・金額を手入力で修正してください。撮り直す場合は、影や反射を避け、文字にピントを合わせます。撮影ガイドラインもご確認ください。

複数枚のうち、一部の領収書が取り込まれません

読み取り前の枠確認画面で、すべての領収書に枠があるか確認してください。枠がない場合は「＋」で追加し、四隅を合わせます。最大8枚まで取り込めます。

保存ボタンを押せません

未入力の項目や、金額の形式に問題がないか確認してください。複数枚を登録する場合は、各領収書の入力内容を確認してください。

カメラや写真を利用できません

端末の「設定」でセムカンカメラのアクセス許可を確認してください。写真を選ぶ場合は、表示される写真選択画面から取り込みたい画像を選びます。

送信できません

インターネット接続とログイン状態を確認してください。ログインし直す案内が表示された場合は、再度ログインして送信します。送信が途中で止まった場合は、端末に残っている支出を再送してください。

送信した支出がホームから消えました

送信に成功した支出と画像は、端末から自動削除されます。メニューの「セムカン本体へ」から、送信した内容を確認してください。

解決しない場合は、メニューの「お問い合わせ情報」からお問い合わせください。
